# 记忆上下文包模板

构建 `memory/latest-context-pack.md` 时使用以下结构。

```markdown
# 记忆上下文包

## 来源需求

- 文档：
- 生成时间：
- 关键词：

## 相关项目事实

## 相关领域术语

## 相关历史缺陷和风险模式

## 相关项目测试经验

## 输出偏好

## 约束和非范围

## 已检索但未注入的 Memory
```

## 选择策略

- 只注入能改善本次分析的 memory。
- 优先匹配模块、角色、对象、状态、接口或项目历史缺陷。
- 每条内容保持简洁，并标记来源 memory 文件或来源章节。
- 不注入通用测试理论；通用测试理论从 `knowledge/` 获取，`skills/` 只定义分析动作。
- 构建 context pack 时不修改长期 memory 源文件。
