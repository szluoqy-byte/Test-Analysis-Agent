# 测试判定依据启发

本文件用于判断测试点是否“可验证”。

## 判定依据来源

- 需求文本：明确规则、状态、阈值、接口或验收说明。
- 业务不变量：必须始终成立的业务条件，例如不能重复释放库存。
- 数据不变量：计数、状态、归属、可见性或审计一致性。
- 契约不变量：请求字段、响应字段、错误码、回调或兼容规则。
- 权限不变量：参与方、资源、动作、数据范围、租户和归属关系。
- 历史缺陷：memory 中确认过的失败模式。

## 不变量检查点

| 不变量类型 | 检查点 |
|---|---|
| 业务不变量 | 业务对象是否满足规则、状态是否符合约束、金额/数量是否保持业务含义 |
| 数据不变量 | 主数据和派生数据是否一致、缓存/搜索/统计/导出是否同步、审计日志是否可追踪 |
| 权限不变量 | 角色是否只能访问授权资源、数据范围是否隔离、权限变更是否及时生效 |
| 契约不变量 | 请求字段、响应字段、错误码、兼容策略、幂等键和回调语义是否稳定 |
| 状态不变量 | 终态是否不可变、非法迁移是否被拒绝、重复事件是否不产生重复副作用 |

## 缺少判定依据时

- 不创建假的预期结果。
- 生成“待确认问题”。
- 如有价值，可生成风险确认点，并明确标记需求未完全说明。

## 表达示例

- 好：`验证取消成功后库存释放与订单状态变更保持一致`。
- 差：`点击取消按钮后库存加 1 并显示取消成功`。
